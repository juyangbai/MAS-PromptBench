Tutorial and reference

MAS-PromptBench Docs#

When does prompt optimization improve a multi-agent LLM system? These docs show you how to run the benchmark, optimize system prompts with GEPA or MIPRO, and read the gain they produce.

Get started

9 tasks5 topologies4 frameworks3 protocols4 team sizes2 optimizers

Start here#

  • Overview The model of a multi-agent system, the four factors and the gain \( \Delta \).
  • Installation Clone with submodules and create the conda environment.
  • Connect a Model Use a hosted API or serve Qwen locally with vLLM.
  • Quick Start Baseline, optimize and read the result in five steps.

The benchmark#

Each factor is varied on its own while the others stay at their defaults.

  • Tasks GPQA-Diamond, HotpotQA, MATH, LiveCodeBench, APPS, SWE-bench Verified, BFCL, ToolHop and API-Bank.
  • Workflow Topologies Single, Independent, Sequential, Centralized and Decentralized.
  • Communication Protocols Freeform, Semi-structured and Structured messages.
  • Team Sizes The same topology with 2, 4, 8 and 10 agents.
  • Optimizers GEPA and MIPRO, run over the real topology runners.

Extend and look up#

  • Add a Dataset Runners, scorer, output contract, eval IDs, prompts and optimizer adapter.
  • Add a Topology A new coordination structure or a framework variant of an existing one.
  • Command-Line Flags Every runner and optimizer flag, with defaults.
  • Read the Results The files an optimizer run writes and how to turn them into numbers.
